⚙️ HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OLLAMA PATH (Free, Local):
   Frontend
      ↓
   AI Sidecar (Express)
      ↓
   Ollama Container (LLM)
      ↓
   Response (no external API calls)

OPENAI PATH (Paid, Cloud):
   Frontend
      ↓
   AI Sidecar (Express)
      ↓
   OpenAI API (requires internet + billing)
      ↓
   Response

SWITCH BETWEEN THEM:
   Edit .env:
   AI_PROVIDER=ollama    or    AI_PROVIDER=openai
   Restart:
   docker-compose restart ai-sidecar

❓ FAQ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Can I use both Ollama and OpenAI?
A: Yes! Set AI_PROVIDER=ollama with OPENAI_API_KEY set. Ollama is primary.

Q: What if Ollama is too slow?
A: Use a smaller model (orca-mini) or switch to OpenAI.

Q: What if I run out of disk space?
A: Delete unused models: docker-compose run ollama ollama rm mistral

Q: Can I use Ollama offline?
A: Yes! After the model downloads, everything works without internet.

Q: How do I switch models?
A: Edit .env (OLLAMA_MODEL=zephyr) and restart ai-sidecar.

Q: Is Ollama secure?
A: Yes, everything runs locally on your PC. No data leaves your machine.

Q: Can I use Ollama in production?
A: Yes, but responses will be slower than OpenAI. Good for internal tools.

Q: What's the biggest model that fits in 8GB RAM?
A: Mistral (5GB) or Zephyr (5GB) work fine. Larger models need 16GB+.
